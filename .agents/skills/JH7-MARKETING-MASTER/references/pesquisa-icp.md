# Pesquisa, Voz do Cliente, ICP e posicionamento

Carregue para: pesquisar mercado e concorrentes, extrair linguagem do cliente, definir ICP/persona, construir posicionamento.

---

## 1. Pesquisa de concorrentes

O que analisar em cada concorrente relevante (3–5 diretos):

| Item | Onde olhar |
| --- | --- |
| Posicionamento e promessa | site, bio das redes |
| Preço e condições | site, tabela, WhatsApp como cliente oculto |
| Oferta e diferencial | página de vendas |
| Anúncios ativos | Biblioteca de Anúncios da Meta, busca no Google |
| Criativos e ângulos | anúncios ativos e há quanto tempo rodam |
| Reclamações | Google Reviews, Reclame Aqui, comentários |
| Elogios | reviews positivos (mostram o que o mercado valoriza) |
| Conteúdo e SEO | páginas que ranqueiam, blog, páginas locais |
| Prova social | número de reviews, nota, casos |
| Canais | onde investem consistentemente |

Anúncio que roda há muito tempo é sinal de que funciona. Use como referência de ângulo, nunca copie criativo nem copy.

Entregue a análise como tabela comparativa + **onde existe espaço não ocupado**. A conclusão útil não é "o concorrente faz X", é "ninguém está atacando Y, e Y importa para o cliente".

## 2. Voz do Cliente (VoC)

A melhor copy não é inventada, é coletada.

**Onde buscar:** reviews do Google e do concorrente, Reclame Aqui, comentários em anúncios e posts, conversas de WhatsApp do próprio negócio, tickets de suporte, grupos e fóruns, Reddit, YouTube, perguntas do "as pessoas também perguntam".

**O que extrair:**
- dores, com as palavras exatas usadas;
- desejos e resultado esperado;
- objeções e medos;
- motivo de compra e motivo de não compra;
- termos que o cliente usa (raramente é o jargão da empresa);
- comparações que ele faz.

**Como usar:** frases reais de cliente viram headline, hook e FAQ. Reclamação recorrente sobre o concorrente vira diferencial na copy. Dúvida repetida no atendimento vira seção da página.

Registre os achados em `MARKETING_CONTEXT.md` para não repetir a pesquisa.

## 3. ICP e persona

**B2C**

| Campo | Exemplo |
| --- | --- |
| Faixa de idade | 28–45 |
| Localização | raio de 15 km de [cidade] |
| Contexto de vida | mãe, primeira casa, trocando de carro |
| Problema | não confia em oficina |
| Desejo | resolver rápido e sem retrabalho |
| Medo | ser enganada no preço |
| Objeção | "será que é caro?" |
| Gatilho de compra | quebrou, mudou, ganhou aumento, data comemorativa |
| Poder de compra | ticket viável |
| Urgência | alta / média / baixa |

**B2B**

| Campo | Exemplo |
| --- | --- |
| Segmento | clínicas odontológicas |
| Tamanho / faturamento | 3–10 funcionários |
| Decisor | sócio-proprietário |
| Influenciador | gerente / recepção |
| Usuário | equipe de atendimento |
| Problema | agenda com buraco |
| Custo do problema | R$ X por cadeira vazia por dia |
| Maturidade | já anuncia? tem CRM? |
| Processo de decisão | 1 reunião, decisão em 1–2 semanas |
| Critério de escolha | prova de resultado no mesmo segmento |

Em B2B, quantifique o custo do problema. É o argumento mais forte da copy.

Defina também o **anti-ICP**: quem você não quer atender. Serve para excluir público, calibrar formulário e escrever copy que filtra.

## 4. Posicionamento

Template:

```
Para [ICP específico]
que enfrenta [problema específico],
a [empresa] é a [categoria]
que entrega [resultado concreto]
através de [mecanismo único],
diferente de [alternativa atual]
porque [prova / razão defensável].
```

Teste de qualidade:
- O concorrente pode dizer a mesma frase? Se sim, está genérico.
- O cliente reconhece o problema na primeira leitura?
- Existe prova para sustentar?

Descarte: "qualidade e confiança", "excelência no atendimento", "soluções sob medida", "o melhor do mercado". Não dizem nada e não são defensáveis.

Bom posicionamento é específico e às vezes exclui parte do mercado de propósito. Isso é uma vantagem, não um problema.

## 5. Pesquisa com informação atual

Quando o assunto depender de dado recente (mudança de plataforma, formato novo, benchmark, tendência, regulamentação, privacidade), pesquise antes de responder.

Hierarquia de confiança:
1. Documentação oficial (Meta Business/for Developers, Google Ads Help, Search Central, Think With Google, Microsoft Advertising)
2. Dados do próprio projeto (CRM, financeiro, plataformas)
3. Estudos e pesquisas de mercado com metodologia declarada
4. Publicações especializadas reconhecidas
5. Opinião de mercado / especialista

Sempre marque o que é oficial e o que é opinião. Opinião de guru não é fato. Benchmark de terceiro é referência, nunca meta — a meta vem do cálculo de margem do projeto (`diagnostico.md`).
